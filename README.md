# KCX

A personal utility CLI tool.

## Installation

```bash
curl -sSL https://raw.githubusercontent.com/kcterala/kcx/main/install.sh | bash
```

## Commands

### `kcx ip`

Retrieves your current IP address and automatically copies it to the clipboard for quick access.


### `kcx now`

Displays current time across multiple timezones for global coordination.

### `kcx auto-update`

Automated Git branch synchronization tool that keeps your local branches up-to-date with remote repositories on a scheduled basis.

**Features:**
- Interactive branch selection
- Remote repository selection
- Configurable cron schedule
- Automatic local branch updates
